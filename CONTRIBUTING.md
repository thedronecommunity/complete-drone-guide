# Contributing to The Complete Drone Guide

Thank you for your interest in improving this guide! 🚁

Whether you're fixing a typo, adding a diagram, or writing a new section — every contribution helps the community.

---

## Ways to Contribute

### 🐛 Fix Errors
- Typos and grammar
- Incorrect commands or parameters
- Outdated information
- Broken links

### 📝 Improve Content
- Better explanations
- More examples
- Clearer diagrams
- Additional tips

### ➕ Add New Content
- New topics not covered
- Translations
- Video tutorials (link them)
- Diagrams and images

### 💬 Share Feedback
- What's confusing?
- What's missing?
- What helped you most?

---

## How to Contribute

### Quick Fixes (Typos, Small Errors)

1. Click "Edit" on the file in GitHub
2. Make your change
3. Submit a Pull Request

### Larger Changes

1. **Fork** the repository
2. **Clone** your fork
   ```bash
   git clone https://github.com/YOUR-USERNAME/drone-workshop-guide.git
   ```
3. **Create a branch**
   ```bash
   git checkout -b fix/your-change-description
   ```
4. **Make changes**
5. **Commit**
   ```bash
   git commit -m "Fix: description of change"
   ```
6. **Push**
   ```bash
   git push origin fix/your-change-description
   ```
7. **Open Pull Request** on GitHub

## Style Guide

### Writing Style

- **Be clear** — Assume reader is a beginner
- **Be practical** — Include commands, not just theory
- **Be concise** — Get to the point
- **Be friendly** — We're all learning

### Formatting

#### Headers
```markdown
# Guide Title (H1 - only one per file)
## Major Section (H2)
### Subsection (H3)
```

#### Code Blocks
```markdown
```bash
# Shell commands
command --flag value
```

```python
# Python code
def function():
    pass
```
```

#### Tables
```markdown
| Column 1 | Column 2 | Column 3 |
|----------|----------|----------|
| Data     | Data     | Data     |
```

#### Tips and Warnings
```markdown
**Tip:** Helpful information here.

**Warning:** Important safety note here.
```

### File Naming

- Lowercase with hyphens: `07-assembly-guide.md`
- Numbered prefix for ordering: `01-`, `02-`, etc.
- Descriptive names

---

## What Makes a Good Contribution

✅ **Good:**
- Tested and verified information
- Clear, step-by-step instructions
- Specific commands with correct syntax
- Safety warnings where needed
- Credit to original sources

❌ **Avoid:**
- Unverified "I think this works"
- Copy-paste without attribution
- Overly complex when simple works
- Missing safety considerations

## Pull Request Template

When opening a PR, include:

```markdown
## Description
Brief description of changes

## Type
- [ ] Fix (correcting errors)
- [ ] Improvement (better explanations)
- [ ] New content (adding topics)
- [ ] Other

## Checklist
- [ ] I've tested commands/code (if applicable)
- [ ] I've checked for typos
- [ ] I've followed the style guide
```
